# آیکون نرم‌افزار امن‌سازی کد

**ایده:** یک سپر سفید و نرم با دو چشم (کاراکتر نگهبان) روی زمینهٔ خاکستری گرادیانی — هم‌سبک با نمونهٔ ارسالی.

## فایل‌ها
| فایل | کاربرد |
|---|---|
| `AppIcon.icns` | macOS (16 تا 1024) |
| `AppIcon.ico` | Windows (16، 24، 32، 48، 64، 128، 256) |
| `AppIcon_AllSizes.zip` | همهٔ PNGها + فایل‌های SVG قابل ویرایش |
| `preview.png` | پیش‌نمایش همهٔ اندازه‌ها |

## مشخصات
- macOS: مربع گرد با حاشیهٔ استاندارد (824px در بوم 1024) و سایه
- Windows: تقریباً تمام‌قد با گوشه‌های گرد کمتر
- رنگ‌ها: زمینه `#9BA1AA → #5D626B`، سپر `#FFFFFF → #E6E8EB`، چشم‌ها `#6F747C`
