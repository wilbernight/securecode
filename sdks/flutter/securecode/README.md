# securecode — Flutter licensing plugin

> **فارسی:** پلاگین Flutter برای سیستم لایسنس SecureCode — همان سریال‌های
> Ed25519 محافظ، با قفل سخت‌افزاری، انقضا، گارد ساعت و anti-debug. لایه Dart
> یک پوشش تایپ‌شده روی SDKهای بومی (Kotlin برای اندروید، Swift برای
> iOS/macOS) است؛ همه چیز آفلاین است.
>
> **English:** the Flutter plugin for the SecureCode licensing system — the
> same Ed25519-signed serials as the protector, with hardware lock, expiry,
> clock guard and anti-debug. The Dart layer is a thin typed wrapper over the
> native SDKs (Kotlin on Android, Swift on iOS/macOS). Everything is offline.

* Platforms: **Android, iOS, macOS** (`sharedDarwinSource` → one Swift plugin
  for both Apple OSes; needs Flutter 3.27+).
* Dart SDK >= 3.2. Zero Dart dependencies beyond Flutter; zero native
  dependencies beyond the platform SDKs themselves.

## The one rule: never hand-edit the native folders

The plugin must be self-contained, so its `android/…/com/securecode/protection`
and `darwin/Classes/SecureCodeKit` trees are **copies** of
`sdks/android/securecode-sdk` and `sdks/apple/SecureCodeKit`. They are
regenerated by:

```bash
python sdks/sync_native.py          # copies both trees into the plugin
python sdks/sync_native.py --check  # verifies the copies are in sync
```

After ANY change to either native SDK, re-run the sync (the repo's CI-style
check runs `--check`).

## Install

```yaml
# pubspec.yaml
dependencies:
  securecode:
    path: ../sdks/flutter/securecode
```

(or publish the folder to your private pub server — `publish_to` is set to
"none" for local use.)

## Usage

```dart
import 'package:securecode/securecode.dart';

final secureCode = SecureCode.instance;

// once at startup
await secureCode.initialize(ProtectionConfig(
  productId: '7e9a6cec-c185-45bb-a2fb-d31e96484f7e',   // demo product
  productName: 'MyApp',
  publicKeyHex: '…your Ed25519 public key hex…',        // demo key is the default
));

// activation screen
final machineCode = await secureCode.machineCode();      // XXXX-XXXX-XXXX-XXXX
final result = await secureCode.activate(serialFromUser);
if (result.state == LicenseState.valid) {
  // unlock: result.payload?.customer / .expiresAtUnix / .featureFlags
}

// every launch
final status = await secureCode.verifyInstalled();
if (status.isValid) {
  // start the app (status.secondsLeft, status.payload…)
}
```

`LicenseState` maps 1:1 to the native enum names: `valid, missing, invalid,
expired, wrongMachine, revoked, clockTampered, damaged, degraded`.

Full API surface (all `async`):

| Method | Purpose |
|---|---|
| `initialize(config)` | embed config + bootstrap the native runtime |
| `machineCode()` | this device's fingerprint code |
| `activate(serial)` | verify + write the encrypted license file |
| `verifyInstalled()` | launch verification (all nine states) |
| `degraded()` | anti-RE silent-degrade flag (feed into UI decisions) |
| `exportFingerprintFile(path)` | write the fingerprint.txt export (with `"platform"`) |
| `makeDeactivationRequest(path)` / `deactivateWithPermit(path)` | machine-transfer flow |
| `installedCustomer()` / `installedExpiresAt()` | quick badge queries |
| `runSelfTest(vectorsJson)` | native selftest report (`{sdk, all_ok, results}`) |
| `shutdown()` | stop watchdog threads on clean exit |

A complete activation + verification flow ships in `example/` (with
`vectors.json` as an asset for the selftest demo).

## Verify the port

```bash
cd sdks/flutter/securecode
flutter test          # Dart-side unit tests (mocked channel)
cd example
flutter run           # full flow on a device/emulator
```

The native layers are already covered by the Gradle / Swift vector suites of
the main SDKs (the plugin embeds the same code via the sync).

## Before release

Same checklist as the native SDKs (embed YOUR public key, rotate masters via
`python sdks/gen_strings.py`, `devMode` off) — see
